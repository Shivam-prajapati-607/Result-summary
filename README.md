# Result Summary Component

A responsive **Result Summary Component** built using **HTML and CSS**.
This component displays a user's overall result along with individual category scores and a summary section.

## 🚀 Features

* Responsive design
* Result score section
* Category-wise scores
* Clean and modern UI
* Mobile-friendly layout
* Hover effects on the Continue button

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* Responsive Design

Result_Summary/

## 💻 How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

Or use the **Live Server** extension in VS Code.
